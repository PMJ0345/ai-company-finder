# AI Company Finder v4.6

Generates structured company insight reports for MJID.dk with initials, logo, and compact PDF layout.

## Features
- Shows all 10 questions before answers
- Inserts company logo automatically
- Adds initials + date in header
- Compact text layout for print-friendly PDF

## Deployment
1. Push this folder to GitHub.
2. On Streamlit Cloud, set main file to `ai_company_finder_v4_6_full.py`.
3. Add your OpenAI API key under Secrets as:
   OPENAI_API_KEY = "sk-xxxx"
4. Deploy and open the app in your browser or on iPhone.
